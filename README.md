## 🏥 MedWatch PMS
### 의료기기 시판 후 안전관리·리콜 업무 지원 시스템

[🔗 Repository](https://github.com/junhaj27-jpg/medical-divice-pms)

의료기기 출시 후 발생하는 고객 불만, 이상사례, 위험평가, CAPA, 규제보고 검토와 리콜을 하나의 사건 흐름으로 연결하는 RA·QA 포트폴리오 프로젝트입니다.

**불만 접수 → 이상사례 판단 → 위험평가 → CAPA → 규제보고 검토 → 리콜 검토 → 승인 → 조치 완료·종료**

단순한 업무 등록을 넘어, 단계별 진행 조건과 담당자 권한을 확인하고 판단 근거·승인 자료·변경 이력을 추적할 수 있는 구조를 중심으로 개발하고 있습니다.

### 🛠️ 프로젝트 기술 구성

| 분야 | 기술 및 활용 |
|---|---|

프로젝트에 포함된 기술 구성과 실제 운영 환경에서의 검증 여부는 구분하여 관리합니다.

### 주요 개발 내용

#### 1. 사건 중심 PMS 업무 흐름

- 고객 불만과 제품·UDI·LOT 정보 연결
- 이상사례, 위험평가, CAPA, 규제보고와 리콜의 사건별 통합 조회
- 단계별 상태 전이와 선행조건 검증
- 담당 업무·기한·개인별 할 일·알림 관리

#### 2. 역할별 접근 통제

- STAFF·RA_QA·ADMIN 역할별 업무 범위 구분
- STAFF의 본인 접수 사건 조회 제한
- 화면과 API의 객체 접근 권한 검사
- 관리자 승인과 반려 사유 기록

#### 3. 위험평가와 CAPA

- 심각도와 발생 가능성에 따른 위험점수·등급 계산
- 제품·LOT 기준 반복 불만 탐지
- 고위험 사건의 CAPA 등록 선행조건 검증
- 원인 분석, 시정·예방조치, 담당자와 기한 관리
- 효과성 평가 이력과 미흡 시 재조치 연결

위험등급과 탐지 기준은 시연용 내부 규칙이며, 실제 법정 판단 기준과 구분합니다.

#### 4. 리콜과 회수 이력

- 대상 LOT·시리얼과 리콜 사건 연결
- 거래처별 통보·회신·부분 회수 이력 관리
- 회수 수량과 회수율 계산
- 미회수 사유와 후속 연락 기록
- 리콜 승인·반려 및 종료 보고서 출력

#### 5. 규정 근거와 보고 규칙 관리

- PDF·TXT 규정 문서와 출처·버전·시행일 등록
- 페이지·절·문단 단위 근거 검색
- 규칙 항목별 원문 인용과 담당자 해석 연결
- 초안·검토·승인·시행·폐기 상태 관리
- 작성자와 승인자 분리
- 규칙 버전 비교와 변경 이력 보존
- 기한 계산 미리보기와 사건별 명시적 적용
- 적용 당시 규칙·입력·계산 결과의 스냅샷 보존

실제 법정 규칙이나 최신 공휴일을 자동 제공하지 않습니다. 등록된 근거와 확인된 계산 조건을 담당자가 검토하는 구조입니다.

#### 6. RA 업무 도우미

- 접근 가능한 사건의 상태·고위험·기한 초과 현황 조회
- CAPA·리콜 진행 상황과 PMS 업무 절차 안내
- 사용자별 대화 분리
- 직접 식별정보 입력 차단과 감사 로그 최소화

현재 기본 도우미는 로컬 규칙 기반입니다. 규정 초안용 외부 AI 어댑터 구조와 실제 공급자 연동·검증은 구분합니다.

#### 7. 증빙·보고서·추적성

- 승인 요청 시점의 사건 자료 스냅샷
- 주요 업무의 감사 로그
- 증빙 파일 검사 상태에 따른 접근 제한
- 서버 PDF 생성과 보고서 버전 보존
- 백업·격리 복구 절차와 검증 도구 구성

아래 항목은 기존 구현과 구분하여 완료 여부를 관리합니다.

| 독립 검증 에이전트 | 요구사항 대조, 결함 재현, 수정 후 회귀 검증과 보고서 작성 |

### 🧪 검증 방향

- 정상 업무 흐름과 잘못된 상태 전이 차단
- 역할별 화면·API 접근 권한
- 기한 계산과 규칙 적용 근거
- CAPA·리콜 수량·승인 선행조건
- 기존 데이터와 파일 이력 보존
- PostgreSQL 환경의 동시 처리
- AI 모의 테스트와 실제 연동 검증의 구분

테스트 결과는 실행 환경과 기록이 확인된 범위에서 기재합니다. 검증 에이전트가 생성한 보고서도 실제 실행 근거와 함께 검토합니다.

### 구현 범위와 결과 해석

- 연구·취업 포트폴리오용 업무 지원 시스템입니다.
- 실제 규제기관 보고, 법정 규정 준수 또는 의료 판단을 자동 보장하지 않습니다.
- 규정 적용과 최종 업무 판단은 담당자의 검토·승인을 전제로 합니다.
- 구현 완료, 선택적 외부 연동, 추가 개발 목표와 환경별 미검증 항목을 구분합니다.
