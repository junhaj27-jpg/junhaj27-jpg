## 🧠 뇌 나이 예측 AI

### 연구·개발 주제

**임상·뇌 MRI·유전체 데이터를 활용한 가속 뇌 노화 예측 AI 연구**

MRI에서 추출한 뇌 영역별 체적을 활용해 뇌 나이를 예측하고,
실제 나이와의 차이를 분석하는 프로젝트입니다.

### 핵심 입력과 분석 방향

| 데이터 | 활용 방향 |
|---|---|
| MRI 66개 뇌 영역 체적 | 뇌 나이 예측의 기본 입력 |
| 임상정보 | 예측 모델 입력 및 관련 요인 분석 |
| SNP·유전체 | 선택적 결합 및 관련 요인 탐색 목표 |
| 원본 3D MRI | 영상 모델 확장·학습 영역 |

MRI 체적 CSV를 사용하는 분석과 원본 3D 영상을 직접 학습하는 분석은 구분하여 진행합니다.

### 분석 흐름

1. 데이터 구조와 변수 확인
2. 결측치 처리 및 전처리
3. 대상자 단위 학습·검증·평가 데이터 분할
4. 기준 모델과 후보 모델 학습
5. 예측 성능 및 연령대별 오차 분석
6. BAG 계산과 결과 시각화

### 비교·실습 모델

- DummyRegressor
- Ridge
- RandomForestRegressor
- SVR
- XGBRegressor

### Brain Age Gap

**BAG = 예측 뇌 나이 − 실제 나이**

- 양수: 예측 뇌 나이가 실제 나이보다 높음
- 음수: 예측 뇌 나이가 실제 나이보다 낮음

BAG는 연구용 분석 지표로 활용합니다.
연령에 따른 예측 편향과 모델 오차를 함께 확인하며,
값 하나만으로 개인의 질환이나 건강 상태를 판단하지 않습니다.

### 학습용 구현·실행 경험

- 예시 데이터 생성
- 전처리 및 대상자 단위 데이터 분할
- 모델 학습·평가·비교·추론 코드 구성
- 40명 규모의 빠른 실행 및 300명 규모의 전체 실행
- 한글 실습 노트북 14개 코드 셀 순차 실행 검증
- 학습용 프로젝트에서 pytest 18개 통과 확인

위 기록은 학습용 코드와 실행 흐름에 대한 검증 결과이며,
실제 임상 데이터에서의 성능이나 임상적 유효성을 의미하지 않습니다.

### 확장 목표

- 임상정보와 MRI 체적을 결합한 모델 비교
- 3D CNN 기반 영상 모델 탐색
- 선택적 유전체 입력 구조 검토
- 연령 편향 보정 전후 비교
- 모델 해석과 예측 불확실성 분석
- 독립 데이터에서의 일반화 성능 확인

## 📊 인터랙티브 모델 비교 서비스

뇌 나이 예측 모델의 결과를 사용자가 탐색할 수 있는 서비스 개발을 목표로 합니다.

### 주요 기능 목표

- 모델 및 입력 구성 선택
- 모델별 평가 지표 비교
- 실제 나이와 예측 뇌 나이 시각화
- BAG 및 예측 오차 분포 확인
- 분석 조건과 데이터 출처 표시
- 실제 데이터와 예시 데이터 구분

### 평가 항목

| 항목 | 확인 목적 |
|---|---|
| MAE | 평균적인 예측 오차 확인 |
| RMSE | 큰 예측 오차를 포함한 성능 확인 |
| R² | 실제 나이 변동에 대한 설명 정도 확인 |
| 연령대별 오차 | 특정 연령대에 집중되는 오차 확인 |
| BAG와 실제 나이의 관계 | 연령 관련 예측 편향 확인 |

동일한 데이터 분할과 평가 조건에서 모델을 비교하는 것을 원칙으로 합니다.

## 🏥 의료기기 PMS 업무 지원 시스템

의료기기 시판 후 관리 과정의 업무·기록·후속 조치를
체계적으로 관리하기 위한 시스템을 개발하고 있습니다.

### 개발·고도화 항목

| 항목 | 주요 내용 |
|---|---|
| 담당 업무·기한 관리 | 담당자 지정, 마감일, 개인별 할 일 |
| CAPA 관리 | 조치 이력, 증빙 등록, 효과성 평가 |
| 리콜 회수 이력 | 거래처별 통보·회신·회수 수량·미회수 사유 |
| 보고 규칙 버전 관리 | 적용 조건, 시행일, 규칙 변경 이력 |
| 보고서 출력 | 업무 기록과 증빙을 보고서로 정리 |

### 설계 방향

- 업무 이력과 변경 사항의 추적성 확보
- 담당자가 검토·승인할 수 있는 업무 흐름
- 규칙의 적용 시점과 버전 구분
- 규정 근거와 검토 기록을 연결하는 구조
- 사용자 입력 규칙과 확인된 법정 기준의 명확한 구분
